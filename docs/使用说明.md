# 群晖电信同步工具 · 使用说明

群晖 NAS 套件，把本地文件夹同步到天翼网盘，支持校验一致后删除源文件。

---

## 一、安装

### 步骤 1：先装 Python 3

套件中心 → 安装 **Python 3**（需 3.8+，推荐 3.9+）。

套件自带 `httpx`、`pycryptodome` 等依赖，不需要额外装 Python 包。
安装前若检测不到 Python，套件会直接中止并提示。

### 步骤 2：安装套件

套件中心 → 安装套件 → 选择与你的 NAS 架构匹配的包 → 勾选「安装后运行」。

```
qunhuisync_x86_64-7.2_1.4.1-0004.spk     Intel / AMD 群晖
qunhuisync_armv8-7.2_1.4.1-0004.spk      ARM64 群晖（DS920+ 等）
```

> 查看 NAS 架构：控制面板 → 信息中心 → 硬件，或 SSH 执行 `uname -m`
> （`x86_64` / `aarch64`）。

> **升级安装**：版本号每次变更都会递增，直接在套件中心上传新包即可，
> DSM 会识别为升级并保留已有的账号配置与令牌，**不需要先卸载**。
> 版本号相同的包无法覆盖安装。

安装过程会自动：
1. 以系统内部用户 `sc-qunhuisync` 身份准备运行环境（DSM 7 强制降权）
2. 装载该架构的加密库（`pycryptodome` 预编译包）
3. 写入默认配置到 `/var/packages/qunhuisync/var/config/`
4. 启动服务

### 步骤 3：打开界面

```
http://<群晖IP>:8686/
```

### 可选：挂到 DSM 域名下

SSH 执行：

```sh
sudo /var/packages/qunhuisync/scripts/add-proxy.sh
```

之后访问 `http://<群晖IP>/webman/3rdparty/qunhuisync/`。

> 更稳妥的做法是在 DSM「控制面板 → 登录门户 → 高级 → 反向代理」里手动加一条
> 源路径 `/webman/3rdparty/qunhuisync/`，目标 `http://127.0.0.1:8686/`。

## 二、首次配置（3 步）

### 第 1 步：登录天翼网盘

打开「天翼网盘账号」面板，点右上角「**扫码登录**」：

1. 页面出现二维码
2. 用手机上的「**天翼云盘**」App 扫描
3. 在手机上确认登录
4. 页面提示「登录成功」，右上角状态条变成「已连接」

> **只用扫码登录**。天翼现行网页版的密码登录是网易易盾**滑块**，
> 无法自动通过，所以界面不提供密码输入框。登录状态会保存下来，
> 套件重启后自动续期，不用重新扫码。

### 第 2 步：其余设置

| 字段 | 填什么 |
| --- | --- |
| 根目录 ID | 保持 `-11` |
| 上传线程数 | 同时上传几个文件，默认 3，可选 1-8 |
| 网页访问密码 | 留空表示界面不设密码 |

填完点「保存账号设置」。

### 第 3 步：建第一条规则

点「新建规则」：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 规则名称 | 家庭照片归档 | 随便起，便于识别 |
| 本地目录 | `/volume1/photos` | 点「浏览」逐级选，不用手打 |
| 远端目录 | `/群晖电信同步/照片` | 不存在会自动创建 |
| 文件类型过滤 | `*.mp4` | 逗号分隔多个，如 `*.mp4, *.mkv`；留空 = 全部文件 |
| 排除规则 | `*.tmp` | 命中即跳过 |
| 最小文件大小 | `1` + 单位 `KB` | 跳过比这更小的文件；单位可选字节 / KB / MB / GB |
| 删除 0 字节文件 | 打开 | 空文件直接清理，不上传 |
| 计划 | 每天定时 02:00 | 或 每 30 分钟 / 仅手动 |

> **例：只同步大于 1KB 的 MP4**
>
> 「文件类型过滤」填 `*.mp4`，「最小文件大小」填 `1`、单位选 `KB`，保存即可。
> 类型匹配不区分大小写，`*.mp4` 同时匹配 `a.mp4` 和 `A.MP4`，且对任意层级的子目录都生效。

保存后点「立即同步」试跑一次。

> **关于「删除 0 字节文件」**
>
> 打开后，命中的空文件**在本地直接删掉**，不上传到网盘，也不进回收站
> （空文件本来就没有内容，找回没意义）。
>
> 它和「最小文件大小」互不影响：体积门槛决定**哪些文件要上传**，
> 0 字节规则决定**哪些空文件要删掉**。即使设了「大于 1KB」，空文件照样会被清理。

## 三、目录权限授权（DSM 7 必读）

DSM 7 起，群晖要求**未签名的第三方套件不得以 root 身份运行**——套件中心会直接拒绝安装
「以 root 权限运行」的套件。本套件以系统内部用户 `sc-qunhuisync` 身份运行。

后果是**新装的套件对所有共享目录都没有读写权限**，需要手动授权一次。

### 查看哪些目录缺权限

Web 界面顶部会出现「目录权限」区块，列出权限不足的目录；规则卡片上也会标
「目录无读写权限」。点「重新检查」随时刷新。

### 授权方式（任选其一）

**方式 A：DSM 界面（推荐）**

1. 控制面板 → **共享文件夹** → 选中目标目录 → **编辑**
2. 切到 **权限** 标签页
3. 下拉框选 **系统内部用户**
4. 找到 `sc-qunhuisync`，勾选 **读写**
5. 确定

> 授权子目录时，父目录也要有「浏览文件夹」权限，否则进不去。

**方式 B：SSH 一键授权**

```sh
sudo /var/packages/qunhuisync/target/scripts/grant-access.sh /volume1/photos
# 可一次传多个目录
sudo /var/packages/qunhuisync/target/scripts/grant-access.sh /volume1/photos /volume1/videos
```

脚本用 `synoacltool` 授予读写权限，并自动处理父目录遍历权限。

### 为什么必须授权

「同步成功后删除源文件」需要**删除**权限，写回收站需要**写**权限。
只有读权限时上传能成功但删除会失败——此时套件会**保留源文件**并在日志写明
「删除源文件失败」，不会丢数据。

## 四、规则选项详解

### 文件类型过滤怎么写

| 写法 | 含义 |
| --- | --- |
| `*.jpg` | 按**文件名**匹配，大小写不敏感，`a.JPG` 也命中 |
| `子目录/*.mp4` | 按**相对路径**匹配 |
| `**/*.png` | 任意层级的 png，包括顶层 |
| `*.jpg, *.png` | 多个用逗号分隔 |

### 「同步成功后删除源文件」

这是本套件的核心能力，执行流程严格分三步：

```
1. 上传文件到天翼网盘（整文件一次性上传）
2. 重新读取云端目录，核对文件名与大小
   （若选 MD5 校验，再回读云端文件算哈希与本地比对）
3. 校验通过 → 直接删除源文件
   校验不通过 → 保留源文件，日志标注「校验未通过」
```

几个要点：

- **没有回收站**：校验通过后源文件直接删除，不留任何副本，**误删无法找回**
- 「删除 0 字节文件」规则同样是直接删除
- **建议先关掉这个开关跑一次**，确认上传结果无误后再打开

### 校验方式选哪个

| 选项 | 速度 | 可靠性 | 建议 |
| --- | --- | --- | --- |
| 大小一致 | 快 | 高 | 默认，绝大多数场景够用 |
| MD5 强校验 | 慢一倍（要回读云端文件） | 最高 | 重要归档文件用 |
| 不校验 | 最快 | 低 | 不建议 |

### 增量机制

每次同步会把「文件大小 + 修改时间」记到 `state.json`。下次扫描时：

- 大小和修改时间都没变 → **直接跳过**，不重复上传
- 本地记录丢了（重装套件等）→ 自动退化为「云端同名且大小一致」判断，同样不会重复上传
- 大小不一致 → 视为文件已更新，先删云端同名文件再上传

## 五、日常使用

### 手动同步

界面规则卡片点「立即同步」，任务在后台线程跑，界面不卡。

首页的「当前任务」面板**只显示正在跑的任务**，跑完自动移出。
**并发的每个文件各占一行**，各自显示：

- 文件名
- 已传 / 总量（如 `6.0 MB / 41.0 MB`）
- 实时上传速度（如 `5.2 MB/s`）
- 独立的进度条与百分比
- 独立的「取消此文件」按钮

顶部还有「第 3 / 12 个文件」的整体进度和上传 / 失败计数。

### 上传方式

按 OpenList 的机制**整文件一次性上传**（不分片），天翼自己负责断点续传。
传输中断时套件会查服务端实际收到的字节数，**从断点继续**，不会从头再来。

分片大小由天翼按文件大小硬性规定（≤10GB 用 10MB，~100GB 用 20MB，~200GB 用 50MB），
套件自动计算，不需要也不能手动设置。

### 取消同步

有两种粒度：

| 按钮 | 位置 | 效果 |
| --- | --- | --- |
| **取消此文件** | 每个文件行内 | 只停这一个文件，其它文件继续传 |
| **取消整个任务** | 任务卡片底部 | 当前文件传完后整个任务停止 |

已传完的文件保留在网盘上，不会留下半个文件。

### 并发上传

账号设置里的「上传线程数」决定同时上传几个文件，默认 3（1-8）。

- 线程多速度快，但天翼对并发敏感，太多可能触发限流
- 网络不稳时调到 1-2 更稳
- 界面上每个并发文件各占一行，都能单独看到进度和速度

### 定时同步

- **每 N 分钟**：距上次执行超过间隔就自动跑
- **每天定时**：到点跑一次，当天不会重复触发
- 调度线程每 30 秒检查一次

### 查看任务日志

日志单独开一页：点任务卡片上的「**查看日志**」，或直接访问
`http://<群晖IP>:8686/logs.html`。

左边是历史任务列表，右边是完整日志，可勾选「自动刷新」：

```
[2026-10-28 02:00:01] 开始同步：本地 /volume1/photos -> 云端 /群晖电信同步/照片
[2026-10-28 02:00:01] 扫描到 9 个待同步文件
[2026-10-28 02:00:01] 删除 0 字节文件 2 个
[2026-10-28 02:00:01] 清理空目录 1 个
[2026-10-28 02:00:01] 并发上传：3 个线程
[2026-10-28 02:00:03] 同步结束：上传 9，跳过 0，删除源文件 9，删除 0 字节 2，失败 0，传输 12.4 MB
```

服务器端日志：`/var/log/packages/qunhuisync.log`，套件中心也能看。

## 六、命令行用法

套件把应用和依赖都放在 `target` 目录，先设 `PYTHONPATH`：

```sh
export PYTHONPATH=/var/packages/qunhuisync/target/deps:/var/packages/qunhuisync/target/app
```

```sh
# 检查配置与依赖
python3 -m qunhuisync check --config /var/packages/qunhuisync/var/config/config.json

# 手动执行一次同步（all 表示所有规则，也可填规则 id 或名称）
python3 -m qunhuisync sync --config /var/packages/qunhuisync/var/config/config.json --rule all

# 启动服务（套件一般已自动启动，手动启动前先在套件中心停止）
python3 -m qunhuisync serve --config /var/packages/qunhuisync/var/config/config.json --port 8686
```

也可以直接调套件脚本：

```sh
sudo /var/packages/qunhuisync/scripts/start-stop-status status
sudo /var/packages/qunhuisync/scripts/start-stop-status log
```

## 八、常见问题

**Q：安装时提示「由于套件以 root 权限运行，因此无法安装」**
A：DSM 7 的强制检查。本套件已改为 `run-as: package`（服务账号 `sc-qunhuisync`）。
若仍出现，说明装的是旧包，先在套件中心卸载旧版本再装新版。

**Q：顶部一直显示「账号未连接」**
A：点右上角「扫码登录」，用天翼云盘 App 扫一次即可。登录状态会保存，
套件重启后自动续期。

**Q：提示「需要图形验证码」**
A：天翼网页版的密码登录已换成网易易盾**滑块**，无法自动通过。
本套件只用扫码登录，不提供密码入口。

**Q：扫码后一直显示「请使用天翼云盘 App 扫码」**
A：确认扫的是「天翼云盘」App（不是中国电信 App），并在手机上点了「确认登录」。
二维码有效期约 2 分钟，过期了点「换一张」。

**Q：上传很慢或中断**
A：把「上传线程数」调大（默认 3）。大文件用「大小一致」校验，避免回读云端。
传输中断时套件会自动查服务端已收到的字节数，**从断点续传**，不用手动重跑。

**Q：日志报「InvalidPartSize」**
A：这是天翼对分片大小的硬性要求（文件 ≤ 10GB 必须 10MB，~100GB 必须 20MB，
~200GB 必须 50MB）。套件已按这个规则自动计算，不用也不能手动改。

**Q：日志报「uploaded part number less than total slice part number」**
A：这是旧版本包的分片上传问题。升级到 1.4.1 及以上版本即可——
新版改成整文件上传（OpenList 的 old 机制），不再有这个问题。

**Q：界面报「刷新失败：Cannot read properties of undefined」**
A：这是旧版本的前端 bug（服务端返回异常时界面崩掉）。1.4.1 已修复：
服务端接口不再阻塞，前端也对异常响应做了兜底。若仍出现，请看服务日志。

**Q：反代报 502 / 服务无响应**
A：旧版本 `/api/state` 会同步调用网盘接口，网络慢时接口被拖死，
反代超时后返回 502。1.4.1 已改为后台刷新容量、接口立即返回。

**Q：界面提示「目录无读写权限」**
A：服务账号没有该目录的权限，按「三、目录权限授权」授权一次即可。

**Q：能上传但删不掉源文件**
A：删除需要写权限。用 DSM 界面或 `grant-access.sh` 授权后重试；失败时套件会保留源文件，不会丢数据。

**Q：文件删了能找回来吗**
A：**不能**。本套件已取消回收站机制，校验通过后源文件直接删除。
重要数据请先备份，或先跑一次不开「删除源文件」的同步确认结果。

**Q：端口 8686 被占用**
A：改 `/var/packages/qunhuisync/var/config/port` 的内容，或改 `config.json` 里的 `server.port`，然后在套件中心重启套件。

**Q：文件被误删了**
A：去同步目录里的 `.qunhuisync_trash` 找，或在界面「回收站」区块里看。
保留期内都能恢复（0 字节文件除外，它是直接删除的）。

**Q：日志报「删除源文件失败 Permission denied」**
A：老版本的回收站建在同步目录的**上级**（比如 `/volume1/.qunhuisync_trash`），
服务账号对上级目录往往没有写权限。新版本把回收站放在**同步目录内部**，
升级后即可正常删除；也可以在配置里指定一个可写的全局回收站路径。

**Q：源文件删了但网盘上文件不完整**
A：不应该发生——校验不通过时源文件会被保留。看任务日志里有没有「校验未通过」。

**Q：想确认能不能连通网盘**
A：界面点「扫码登录」，或命令行执行 `python3 -m qunhuisync check`。

## 九、安全建议

1. **重要数据先备份**，开启「删除源文件」前务必先跑一次不删除的同步
2. 套件以系统内部用户 `sc-qunhuisync` 运行，权限最小化；授权只给需要同步的目录
3. 给界面加访问密码（账号面板里的「网页访问密码」），避免群晖内网其它设备误操作
4. 天翼网盘无官方 API，走网页版接口，天翼改接口会导致套件失效，届时需更新 `pc189` 模块
