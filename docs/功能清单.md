# 群晖电信同步工具 · 功能清单

群晖 NAS 套件（SPK），把本地文件夹同步到天翼网盘。

---

## 一、账号与连接

| 功能 | 说明 |
| --- | --- |
| **扫码登录（唯一方式）** | 用天翼云盘 App 扫码即可登录，不用记密码，也不受天翼风控的滑块验证码影响 |
| 自动续期 | 登录状态会保存，套件重启后自动用令牌续连，不用重新扫码 |
| 真实错误提示 | 天翼返回什么原因就显示什么，不再笼统报「登录失败」 |
| 容量展示 | 顶部状态条显示网盘已用 / 总容量（后台刷新，接口永不卡顿） |
| 上传线程数可调 | 账号设置里调整同时上传的文件数，默认 3，可选 1-8 |
| 自动重试 | 网络抖动或服务端断开时自动续传，单个文件不会因此整个失败 |

## 二、同步规则

| 功能 | 说明 |
| --- | --- |
| 本地目录 | 指定群晖上的源目录，Web 界面可点「浏览」逐级选择，不用手打路径 |
| 远端目录 | 天翼网盘目标路径，**不存在会自动创建**（含多级目录） |
| 按文件类型过滤 | 支持 `*.jpg`（按文件名）、`子目录/*.mp4`（按相对路径）、`**/*.png`（任意层级），大小写不敏感 |
| 排除规则 | 命中即跳过，例如 `*.tmp` |
| 排除目录 | 默认 `@eaDir`、回收站目录，可增删 |
| 递归 / 非递归 | 只同步当前层，或包含所有子目录 |
| 保留目录结构 | 关闭后所有文件平铺到远端目录 |
| 最小文件大小 | 跳过小于指定体积的文件，单位可选字节 / KB / MB / GB（只管「哪些文件要上传」） |
| 删除 0 字节文件 | 命中的空文件**本地直接删除**，不上传（与体积筛选互不影响） |
| 覆盖同名文件 | 云端存在同名但大小不同的文件时，先删除再上传 |
| 保留计划 | 每条规则可单独设置执行计划 |
| 规则启停 | 单条规则随时停用，不影响其它规则 |
| 规则增删改 | 界面完成，删除规则不影响已上传的文件 |

## 三、执行计划

| 类型 | 说明 |
| --- | --- |
| 仅手动 | 只在点「立即同步」或命令行触发时执行 |
| 每 N 分钟 | 距上次执行超过设定间隔就自动跑一次 |
| 每天定时 | 每天指定时间（HH:MM）执行一次，到点不重复触发 |

调度线程每 30 秒检查一次，到点自动触发对应规则。

## 四、增量与重复文件控制

| 机制 | 说明 |
| --- | --- |
| 本地状态记录 | 每次同步记录文件的「大小 + 修改时间」，未变化的文件直接跳过，不重复上传 |
| 云端比对兜底 | 本地记录丢失（如重装）时，退化为按「云端同名且大小一致」判断，同样不会重复上传 |
| 覆盖策略 | 只有大小不一致时才认为需要更新，避免无意义的重传 |

## 五、校验（安全删除的前提）

| 方式 | 说明 |
| --- | --- |
| 大小一致（默认） | 上传后重新读取云端目录，核对文件名与大小 |
| MD5 强校验 | 再回读云端文件计算 MD5 与本地比对，最可靠但流量翻倍 |
| 不校验 | 不推荐，仅在追求速度时使用 |

## 六、删除源文件（无回收站）

| 机制 | 说明 |
| --- | --- |
| 校验后才删 | **只有校验通过才删除源文件**；校验不通过则保留源文件并在日志中标注失败 |
| **直接删除** | 删了就没了，**不留回收站副本**，误删无法找回，请谨慎开启 |
| 0 字节文件 | 走「删除 0 字节文件」规则时直接删除，同样不留副本 |
| 清理空目录 | 可选：同步后删除本地空目录（与上传**分开执行**，不抢 CPU） |

## 七、任务与日志

| 功能 | 说明 |
| --- | --- |
| 立即同步 | 单条规则手动触发，后台线程执行，不阻塞界面 |
| 防重入 | 同一条规则运行中重复触发会被拒绝 |
| 任务统计 | 扫描 / 上传 / 跳过 / 删除源文件 / 失败 / 传输量 |
| **只显示当前任务** | 首页任务面板只列出**正在运行**的任务，跑完即移出，不堆历史 |
| **文件列表** | 并发的每个文件各占一行，各自显示文件名、已传 / 总量、进度条 |
| **上传速度** | 每个文件实时显示传输速度（如 `5.2 MB/s`） |
| **单文件取消** | 每个文件行都有「取消此文件」，只停这一个，其它继续传 |
| **整体取消** | 任务级「取消整个任务」，当前文件处理完后停止 |
| 并发上传 | 按账号设置里的线程数同时上传多个文件，默认 3 |
| 独立日志页 | `/logs.html` 单开一页，列出历史任务并显示完整日志，可自动刷新 |
| 历史保留 | 保留最近 50 次任务，任务历史接口可查 |
| 文件日志 | `/var/log/packages/qunhuisync.log`，套件中心也可查看 |

## 八、Web 界面

| 功能 | 说明 |
| --- | --- |
| 账号面板 | 上传线程数、网页访问密码、扫码登录 |
| 访问密码 | 可给界面加密码（`X-QHS-Password` 头或 Cookie） |
| 规则面板 | 规则列表、状态标识、启停、编辑、删除、立即同步 |
| 目录浏览器 | 在群晖文件系统里逐级选择同步目录 |
| 任务面板 | 只显示当前正在做的任务，每个文件一行进度 + 速度 + 取消按钮 |
| 日志页 | 单独一页看历史任务日志 |
| 自动刷新 | 界面每 4 秒轮询一次状态（接口永不阻塞） |

## 九、命令行

```sh
python3 -m qunhuisync check            # 检查配置与依赖
python3 -m qunhuisync sync --rule all  # 手动执行一次同步
python3 -m qunhuisync serve --port 8686  # 启动 Web 服务
```

## 十、套件管理

| 功能 | 说明 |
| --- | --- |
| 标准 SPK 结构 | INFO / conf/privilege / conf/resource / scripts 完整 |
| 非特权运行 | DSM 7 强制降权，以系统内部用户 `sc-qunhuisync` 运行（`run-as: package`），未签名套件不允许以 root 运行 |
| 目录授权 | 内置 ACL 检测与 `grant-access.sh` 一键授权脚本，同步目录需单独授权读写 |
| 依赖自检 | 安装前检查 Python 3.8+，缺失时给出明确提示 |
| 架构适配 | 内置 x86_64 / aarch64 的 pycryptodome 预编译包，按架构分别出包 |
| 生命周期脚本 | start / stop / restart / status / log，升级含 preupgrade / postupgrade |
| 反向代理脚本 | 可选挂载到 DSM 的 `/webman/3rdparty/qunhuisync/` 路径 |
| 卸载清理 | 自动停止服务、清理账号与代理配置 |

## 能力边界

- 天翼网盘没有官方开放 API，本套件按 OpenList `189pc` 驱动的方式调用网页版接口，
  天翼改接口会导致失效。
- **只用扫码登录**：天翼现行网页版的密码登录是网易易盾滑块，无法自动通过，
  所以界面不提供密码登录入口。
- **整文件上传**：按 OpenList 的 `old` 机制一次性 PUT 整个文件，天翼负责断点续传。
  分片大小由天翼按文件大小硬性规定，套件自动计算，不能手动改。
- 套件以系统内部用户 `sc-qunhuisync` 运行（DSM 7 强制降权），同步目录需单独授权读写。
- 同步为**单向**：本地 → 云端，不做云端到本地的回传。
- **没有回收站**：源文件删除后无法找回，请先跑一次不删除的同步确认结果。
- 不支持跨规则合并同一远端目录的重名冲突处理（后上传的按覆盖策略处理）。
